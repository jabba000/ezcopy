# EzCopy - A simple tool for copying file contents

## What is it?
This tool allows users to conveniently copy a file’s contents with a single command, significantly boosting the efficiency of any task. A very simple script I wrote for my own use. The program simplifies the use of the xclip package for copying file contents.


## Installation
1. Update the packages and install xclip:
`sudo apt update && sudo apt upgrade -y && sudo apt install xclip`

2. Give the newly downloaded cpy file executable permissions and move it to the /usr/local/bin directory.  
`sudo chmod +x ~/Downloads/cpy`  
`sudo mv ~/Downloads/cpy /usr/local/bin`

**Done!**


## Usage:

Simply run the cpy command from anywhere and specify the file whose contents you want to copy. For example:  
`cpy main.py`
